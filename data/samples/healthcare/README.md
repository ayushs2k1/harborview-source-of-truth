# Healthcare sample data

Generated by `scripts/generate_samples.py` (run `make samples`). Deterministic: the same
seed produces byte-identical files, PDFs included.

> This file lives one level above the sample sets on purpose. Anything inside `clean/`
> or `messy/` gets ingested, and an unrecognised Markdown file would be flagged as an
> unknown source type.

## The sets

| Set | What it is |
|---|---|
| `clean/` | Internally consistent. At the pinned as-of date of **2026-09-21** nothing should be raised above INFO. This is the baseline the chaos deck mutates, and the control for "did we just break something". |
| `messy/` | The clean set with specific problems planted. This is what `make demo` ingests. |
| `scan/` | The clean schedule rasterized to an image-only PDF, with no text layer. |

## How it is built

**Coverage first, payroll second.** The schedule is authored to satisfy the domain rules —
an RN on duty eight consecutive hours at every facility every day, an aide on every
facility-day — and payroll is *derived* from it. Payroll written by hand and hoped to
reconcile is how fixtures drift; derived payroll reconciles by construction, so every
variance in the messy set is a visible, deliberate override.

**Census is derived too.** Hours per resident per day is a ratio, so a census invented
independently of the roster would put a compliant schedule in violation. The clean census
is computed backwards from the thinnest staffed day of the week, which keeps the clean
set green when staffing is edited. The messy set ships a realistic, deliberately
under-staffed census so the HPRD rule has something to report.

**Ten people, hand-authored.** `--seed` is accepted and threaded through for the larger
generated sets that come later, but these ten are written by hand: intentional beats
random when every row carries a specific trap.

## Planted problems in `messy/`

Each one names the rule code it exists to raise.

| Planted | Expected |
|---|---|
| Payroll row for someone in no other system | `UNMATCHED_PAYROLL` |
| Agency nurse on the schedule only | `UNMATCHED_SCHEDULE` |
| Schedule drops the accents from a name | still links, no flag |
| Aide certification lapsed mid-week, with shifts after it | `WORKED_AFTER_EXPIRY`, `CREDENTIAL_EXPIRED` |
| Credential expiring 70 days out | `CREDENTIAL_EXPIRING` (warning band) |
| Verification four months old | `VERIFICATION_STALE` |
| HR's expiry disagrees with the service | `HR_LICENSE_EXPIRY_STALE` |
| A week's leave, paid in full | `HOURS_VARIANCE` downgraded, explained by PTO |
| Paid four hours fewer than scheduled | `HOURS_VARIANCE` |
| `7p-7a`, a shift the footnote does not define | `SHIFT_NOT_IN_FOOTNOTE`, `SHIFT_SPANS_PERIOD` |
| `11p-7a`, an overnight the footnote does define | split at midnight in PBJ hours |
| A payroll name written without its quotes | `ROW_DELIMITER_REPAIRED` |
| Riverdale loses its only Sunday RN | `RN_8H_COVERAGE_GAP` |
| The same pay period billed twice | `DUPLICATE_PAY_PERIOD` |
| Facility code `HVB`, in no crosswalk | `CODE_UNKNOWN_FACILITY` |
| Census the roster cannot serve | `HPRD_BELOW_MINIMUM` |
| Vendor permit lapsing inside the window | `CREDENTIAL_EXPIRING` against the organisation |
